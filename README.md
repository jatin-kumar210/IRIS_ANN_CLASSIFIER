# 🌸 Iris Flower Classification using Artificial Neural Network (ANN)

This project is a Deep Learning application that classifies Iris flowers into three species using an Artificial Neural Network (ANN) built with TensorFlow/Keras and deployed using Streamlit.

---

## 🚀 Live Demo

🔗 https://irisannclassifier-mgl47pscslpq68tpztyclq.streamlit.app/

---

## 📌 Features

- 🌸 Predicts Iris flower species
- 🧠 Built using Artificial Neural Network (ANN)
- ⚡ TensorFlow/Keras implementation
- 🎯 Interactive Streamlit interface
- 📊 Real-time prediction

---

```bash

cd IRIS_ANN_CLASSIFIER
pip install -r requirements.txt
streamlit run app.py
```

## 📈 Model

- Input Layer: 4 Neurons
- Hidden Layer(s): ANN
- Output Layer: 3 Neurons (Setosa, Versicolor, Virginica)
- Framework: TensorFlow/Keras
