# 🌸 Iris Flower Classification using ANN

This project predicts the species of an Iris flower using an Artificial Neural Network (ANN) built with TensorFlow/Keras.

## Features

- TensorFlow/Keras ANN
- Streamlit Web App
- Iris Dataset
- Real-time Predictions

## Technologies

- Python
- TensorFlow
- Scikit-learn
- Streamlit
- NumPy

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
